# 日本語学習サイト（Kotsukotsu Japanese）のビルドと公開

英語話者向けの日本語（JLPT語彙）学習サイト。`D:\youph\Project\English`（English Hub）の
姉妹プロジェクトで、同じ静的生成の仕組み・同じフラッシュカード一覧UIを流用している。
**UIは英語**（学習者が英語話者のため）。

## 構成

- ソース: `site/`（ビルダー・テンプレート・CSS/JS）、`content/blog/*.md`（任意）、`site_config.json`
- データ: `data/*.jsonl`（旧 english-learner の `japanese/data/` から移行。1行1語）
- 出力: `dist/`（**コミット対象**。Cloudflare Pages がそのまま配信する）

## ビルド

```
python site/build_site.py
```

- 標準ライブラリのみ（追加インストール不要）
- `dist/` を毎回作り直し、内部リンク切れを検査（切れがあれば exit 1）
- ローカル確認: `python -m http.server 8790 --directory dist` → http://localhost:8790

### ブログ記事を追加したときにもう1つやること

```
python scripts/build_og_images.py blog-covers
```

記事ごとのカバー画像（一覧カードのサムネ＋その記事のOGP）を生成する。
`site/static/og/blog/{slug}.png` と `{slug}-card.webp` が出るので、これもコミットする。
Cloudflare は `dist/` を配信するだけでビルド時に Pillow を動かさないため、
生成物をリポジトリに入れておく必要がある（Pillow はこの生成スクリプトだけが使う）。

回し忘れても一覧・記事ページは壊れず、共通のブログ画像に落ちる（サムネは非表示）。

新しいカテゴリを使うときは `site/templates/blog.py` の `CATEGORY_META` と
`CATEGORY_ORDER` に足す。アクセント色・アイコン・説明文・カテゴリページ・
絞り込み導線がまとめて増える。

## データ形式（`data/*.jsonl`）

1行1語の JSON。`{ id, jp, kana, romaji, en, example_ja, example_en }`。
サイトに出すのは **id / jp / kana / romaji / en** のみ（例文はカードに出さない＝`build_json` が除外）。

| ファイル | 内容 | 件数 |
|---|---|---|
| `vocab_n5.jsonl`〜`vocab_n1.jsonl` | JLPT級別の語彙 | 110/110/200/200/200 |
| `phrases.jsonl` | サバイバルフレーズ | 80 |
| `adult.jsonl` | 成人向け語彙（18+） | 134 |

語彙セットを増やす場合は `data/` にファイルを置き、`site/lib/config.py` の `VOCAB_SETS` に1項目追加。

## コンテンツ方式（重要）

### 語彙フラッシュカード（vocab）
`/vocab/` が入口（index可）、`/vocab/{slug}/` が各カード一覧本体（noindex）。
`site/static/vocab-grid.js` が `static/data/{slug}.json` を読み、全語をカードのグリッドで一覧表示。
各カードは **表(日本語)⇄裏(英語の意味＋読み: かな・ローマ字)** を個別に反転する（English Hub と同じ `.fc-*`）。

- 「Show all meanings」で全カード一括反転
- `#w{id}` … 投稿連動の受け皿。その語のカードへスクロール＆反転＆強調

### 成人向け語彙（adult / 18+）
`/vocab/adult/` は **noindex・ナビ非掲載・sitemap除外**。トップや `/vocab/` からリンクしない
（URLを直接知っている人だけが到達）。ページ冒頭に 18+ の注意書きを表示。
公開したくなければ `config.py` の `VOCAB_SETS` から `adult` を消して再ビルドすればよい。

## 設定（site_config.json）

公開前に差し替えるプレースホルダ:

| キー | 内容 |
|---|---|
| `base_url` | 公開URL（例 `https://kotsukotsu-japanese.pages.dev` または独自ドメイン） |
| `site_name` / `tagline` | サイト名（現在は仮の「Kotsukotsu Japanese」） |

## Cloudflare Pages 初回セットアップ（ダッシュボード側・手動）

1. GitHubにこのリポジトリをプッシュ
2. Cloudflare → Workers & Pages → Create → Pages → Connect to Git
3. このリポジトリを選択し、**Build command は空欄**、**Build output directory は `dist`**
4. 発行URL（`*.pages.dev`）を `site_config.json` の `base_url` に設定 → 再ビルド → コミット

以降は main へのプッシュで自動デプロイ。
