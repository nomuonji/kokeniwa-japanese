# 収益設計（Kotsukotsu Japanese / ja.kokeniwa.net）

英語話者向け日本語学習サイト。**JLPT単語帳（無料ツール）** と **Honne Japan（日本文化記事）** の2本柱。
収益は「Amazon以外の海外アフィリエイト」中心で設計する。

> 方針メモ: このサイトは学習ツールが主役で、無料で価値が完結している。
> 収益は「読者が次に買うもの」（教材・辞書・旅行）に自然に乗せる。

## 対象読者と買うもの

| 読者 | サイトの文脈 | 買う可能性があるもの |
|---|---|---|
| JLPT受験者 | 単語帳を無料で使った | JLPT対策本・問題集・アプリ課金 |
| 日本語学習者 | Honne Japanの文化記事 | 日本語教材・文化関連本 |
| 旅行者 | 文化記事（onsen, izakaya等） | 旅行予約・eSIM・ガイド本 |

## アフィリエイト候補

### 1. Bookshop.org（書籍・本命）

英語話者向けの本（JLPT対策書・日本文化の英語本）を紹介する場合に最適。

| 項目 | 内容 |
|---|---|
| 報酬 | **10%**（Amazon書籍の約4.5%より高い） |
| 地域 | bookshop.org（米国）/ uk.bookshop.org（英国） |
| 相性 | 文化記事（Honne Japan）→「さらに深く知りたい人」に本を勧める導線 |
| 申請 | bookshop.org/affiliate_profile/introduction |

### 2. JLPT・日本語学習の専門書店

- **Tuttle Publishing**（日本関連英語書籍・日本語教材の老舗出版社、自社アフィリエイトあり）
- 英語版JLPT対策本の多くはTuttleやKodansha USAが出版。Amazon以外の直リンクが可能

### 3. 旅行系（文化記事と相性が良い）

Honne Japanの記事（onsen, izakaya, things-to-do-in-tokyo）は旅行者が読む。

- **Klook / GetYourGuide** — 現地体験・アクティビティ
- **Booking.com** — 宿泊
- **eSIM（Airalo等）** — 単価は低いが転換率高

※seichi-atlasと同じ旅行系ASP。そちらの申請が済めば使い回せる。

### 4. 学習アプリ系

- 語学アプリのアフィリエイト（有料プラン成果）— 単価は高いが審査が個別
- 優先度は低い（アプリのレビュー依頼・提携の手間が大きい）

## 優先順位

1. **Bookshop.org** — 本命。文化記事（Honne Japan）に本のリンクを置くだけで自然に機能
2. **旅行系（Klook/Booking）** — onsen/izakaya等の記事に相性が良い
3. Tuttle等の専門書店直リンク — 補助
